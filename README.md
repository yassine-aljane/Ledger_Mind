# LedgerMind

Assistant fiscal pour freelances et créateurs — comprendre, calculer et provisionner ses impôts, sans jargon.

## Développement

Prérequis : [Node.js](https://nodejs.org/) (ou [Bun](https://bun.sh/)).

```sh
git clone <this-repository-url>
cd ledgermind-assistant
npm i
npm run dev
```

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
